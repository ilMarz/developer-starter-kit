# Issue tracker

Il bootstrap imposta un tracker locale, modificabile su richiesta.
Specifiche: `docs/specs/<feature>.md`.
Ticket/slice: un file `docs/work/<feature>/issues/<NN>-<slug>.md` per incremento.
Collegare la specifica e indicare dipendenze per ID; mantenere stato e criteri.
Usare `docs/work/` invece del default upstream `.scratch/`, così i ticket sono versionabili.
Le etichette sono metadati locali: ready-for-agent, needs-info, in-progress, in-review, done.
Nessuna pubblicazione su tracker esterni è configurata. Per cambiarlo leggere la skill setup,
mostrare la proposta concreta e rispettare le autorizzazioni dell'incarico.
