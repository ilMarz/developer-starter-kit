# Issue tracker

The kit import configures a local tracker, which can be changed on request.
Specifications: `docs/specs/<feature>.md`.
Tickets/slices: one `docs/work/<feature>/issues/<NN>-<slug>.md` file per increment.
Link the specification, identify dependencies by ID, and maintain status and criteria.
Use `docs/work/` instead of the upstream `.scratch/` default so tickets can be versioned.
Labels are local metadata: ready-for-agent, needs-info, in-progress, in-review, done.
No external tracker publication is configured. To change this, read the setup skill,
prepare a concrete proposal, and respect the task's authorization boundaries.
